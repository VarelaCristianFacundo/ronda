ronda Sistema de diseño · v1 · Dirección “Libreta”

Tres reglas guían todo: el monto siempre va con su dirección en palabras (“te deben”, “debés”), nunca sólo con color o signo; el color se gana (amarillo = acción principal, verde = te deben, terracota = debés); y la tinta ordena: filas de libreta, líneas finas y cifras tabulares antes que tarjetas.

10 · Decisiones de UX

Dirección en palabras. Cada monto de saldo va acompañado por “te deben”, “debés”, “te debe”, “le debés”. El color refuerza, no informa solo (WCAG 1.4.1, daltonismo).
Sin sumar monedas. El saldo general se muestra por moneda (“En ARS te deben… · En EUR debés…”). Convertir con un tipo de cambio sería inventar un número.
Monto primero. Agregar gasto abre con foco en el monto y el teclado decimal. Pagador y participantes vienen pre-cargados (vos, todos); en el caso típico son dos toques.
El resto se calcula en vivo. En montos y porcentajes una barra fija muestra “Faltan $ 4.000” o “Sobran 5%”. Guardar se deshabilita con el motivo visible, no sólo gris.
Centavos sin drama. Al dividir iguales, los centavos sobrantes se asignan al pagador y se avisa: “Vos absorbés $ 0,01”.
Pagos parciales explícitos. Registrar pago propone el total sugerido y deja editar; muestra “Queda debiendo $ 9.200” antes de confirmar.
Deshacer antes que confirmar. Guardar gasto no pide confirmación; el toast ofrece “Deshacer” 6 s. Eliminar sí confirma, y queda registrado en el historial.
Historial auditable. Cada gasto guarda quién lo creó y cada edición con el valor anterior. En plata compartida la confianza viene de ver los cambios.
WhatsApp primero. Invitar comparte un link por WhatsApp (canal dominante en Argentina); se puede sumar a alguien sin cuenta y reclamar su lugar después.

// Guardar siempre enteros (centavos). Nunca floats.
export type Money = { minor: number; currency: 'ARS'|'USD'|'EUR'|string };

export const fmt = ({ minor, currency }: Money) =>
  new Intl.NumberFormat('es-AR', { style:'currency', currency,
    minimumFractionDigits: minor % 100 ? 2 : 0 })
  .format(minor / 100);            // "$ 62.400" · "US$ 45,00"

// Iguales: reparte el resto de centavos al pagador
export function splitEqual(total:number, ids:string[], payer:string) {
  const base = Math.floor(total / ids.length);
  const rest = total - base * ids.length;
  return ids.map(id => ({ id, minor: base + (id === payer ? rest : 0) }));
}
// Porcentajes: en puntos básicos (100% = 10000), resto al mayor
